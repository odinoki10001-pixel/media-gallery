$notes = @'
## Что нового в v0.3.0

### Уведомления об обновлениях
Приложение теперь само проверяет новые версии на GitHub при запуске и раз в сутки. Если вышла свежая версия — внизу экрана появляется плашка с кнопками «Открыть релиз» и «Позже». В сайдбаре внизу видно текущую версию.

### Исправления
- **Кириллица в путях** — все операции с файлами (удаление в корзину, копирование в буфер) теперь работают через `-EncodedCommand` и `.ps1` в UTF-8 с BOM. Файлы с русскими именами удаляются корректно, пути в буфере не искажаются.
- **Правильное выделение** — рамка мыши больше не «сползает» при прокрутке и не цепляет лишние карточки. Координаты считаются от `main`, а не от `body`.
- **Видео в лайтбоксе** — заработали нативные controls (пауза, перемотка, fullscreen). Раньше клик по видео начинал drag, а не управлял плеером.
- **Пропадающие превью** — если браузер отдавал картинку из кэша без события `load`, она оставалась невидимой. Теперь проверяется `img.complete`.
- **Фото с других дисков** — приложение сканирует все подключённые диски (`D:`, `E:`, …, `/media`, `/mnt`, `/Volumes`), а не только домашнюю папку.

### Установка

1. Скачай `media-gallery-windows.zip` ниже
2. Распакуй, запусти `media-gallery.exe`
3. При первом запуске приложение скачает ffmpeg и ImageMagick для превью — подожди пару минут

WebView2 уже стоит на Windows 10/11.

### Приватность

Никаких сетевых запросов, кроме автоматической загрузки ffmpeg/ImageMagick с официальных источников и проверки новой версии на GitHub. Никакой телеметрии. Вся индексация — локально.
