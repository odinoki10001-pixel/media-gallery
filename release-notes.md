## Что нового в v0.2.0

### Автоматическая установка зависимостей
При первом запуске приложение само скачивает `ffmpeg` и `ImageMagick` с официальных источников в свою папку (`%LOCALAPPDATA%\media-gallery\bin`). Ручная установка больше не нужна — превью видео и RAW работают «из коробки». Прогресс виден внизу сайдбара.

### Улучшено
- **Паттерн сейфа** — переписан с нуля: счётчик точек и подсвеченные точки всегда совпадают, интерполяция движения мыши не даёт «проскочить» точку при быстром рисовании.
- **Поиск** — если FTS5 ничего не нашёл, автоматически идёт fallback на `LIKE` по имени, пути и камере.
- **Удаление в корзину** — все вызовы системных процессов (ffmpeg, PowerShell, cmd) больше не открывают чёрное окно консоли.
- **Счётчики статуса** — «Индексирую: N файлов…», «Превью готово: M». Никаких скачущих процентов.

### Исправлено
- `exec_other.go` и `exec_windows.go` — разделены по платформам, `hiddenCmd` работает и на Linux/macOS.
- Модалка сейфа корректно закрывается по клику на фон.

### Убрано
- **OCR** (Tesseract). Поиск по тексту внутри картинок убран из-за сложности настройки и нестабильного качества. Tesseract больше не скачивается. Поиск по имени, пути и модели камеры работает как раньше.

### Установка

1. Скачай `media-gallery-windows.zip` ниже
2. Распакуй, запусти `media-gallery.exe`
3. При первом запуске подожди пару минут — приложение скачает инструменты для превью

WebView2 уже стоит на Windows 10/11.

### Приватность

Никаких сетевых запросов, кроме автоматической загрузки ffmpeg/ImageMagick с официальных источников. Никакой телеметрии. Вся индексация — локально.
