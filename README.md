# Галерея

> Нативная галерея фото и видео для компьютера — как «Фото» на телефоне, только для всего, что лежит на диске.

## Что это

Windows Explorer, macOS Finder и «Проводник» показывают файлы. Они не показывают **фотографии**. Чтобы найти тот снимок с моря годичной давности, надо помнить папку, имя файла и дату. Это неудобно.

**Галерея** решает одну задачу: собрать все фото и видео с компьютера в одну ленту, сгруппировать по датам, показать превью, дать искать — по имени, по камере, по тексту **внутри** картинки. Как в iPhone, только для ПК и без облака.

Всё локально. Никаких загрузок на сервер, никаких аккаунтов, никакой телеметрии.

## Возможности

### Просмотр
- Единая лента всех фото и видео с диска, отсортированная по дате съёмки
- Автоматические секции: **Сегодня**, **Вчера**, **На этой неделе**, **В этом месяце**, **В прошлом месяце**, потом по месяцам
- Превью **всех** популярных форматов: JPEG, PNG, GIF, WebP, BMP, TIFF, **HEIC/HEIF**, **AVIF**, **RAW** (CR2, CR3, NEF, ARW, DNG, RAF, ORF, RW2 и др.), видео MP4, MKV, MOV, AVI, WebM, WMV, FLV
- Лайтбокс с зумом колесом мыши, перетаскиванием, горячими клавишами
- Видео играется нативно с перемоткой

### Поиск и организация
- **Полнотекстовый поиск** (SQLite FTS5) по имени, пути, модели камеры
- **OCR** — поиск по тексту **внутри изображений** (квитанции, скриншоты, документы): «найди квитанцию за май» работает
- **EXIF**: дата съёмки, модель камеры, GPS
- **Избранное** и **рейтинг** (1–5 звёзд)
- **Альбомы** — виртуальные, файлы физически не двигаются
- **Умные альбомы** — сохранённые фильтры («только 5?», «только с GPS», «видео + избранное»)

### Работа с файлами
- **Множественное выделение**: Ctrl+клик, Shift+клик, рамка мышью
- **Drag-and-drop** файлов прямо из галереи в Telegram, Word, Photoshop, проводник
- **Копирование в буфер обмена** — вставить как файл или как путь
- **Открыть в системном проводнике** одним кликом
- **Удаление в корзину ОС** — восстановимо

### Сейф
- Скрытый альбом, доступ только по паролю
- Тип пароля на выбор: **PIN** (цифры), **текстовый**, **графический паттерн** (3?3, как на Android)
- Хеш пароля через bcrypt
- Файлы, скрытые в сейф, исчезают из основной галереи и поиска
- Пока сейф заблокирован — даже превью недоступны
- Можно удалить сейф: пароль сбросится, файлы вернутся в основную ленту (сами файлы не трогаются)

### Производительность
- **SQLite-индекс** на чистом Go (`modernc.org/sqlite`, без CGO)
- **Инкрементальное сканирование** — повторный запуск на 100 000 файлов занимает секунды
- **fsnotify** — новые файлы появляются в галерее сразу, без перезапуска
- **Ленивая загрузка превью** — при прокрутке битмапы подгружаются и выгружаются из памяти
- **Фоновая очередь** превью и OCR — индексирование идёт тихо, в фоне

### Интерфейс
- Тёмная тема с настоящим глассморфизмом (`backdrop-filter: blur + saturate`)
- Анимированный aurora-фон
- Плавная сетка, работающая на 100 000+ файлов
- Полностью на русском

## Технологии

- **Go 1.22+** — бэкенд целиком
- **[Wails v2](https://wails.io)** — нативная обёртка: WebView2 на Windows, WKWebView на macOS, WebKitGTK на Linux
- **SQLite** через [modernc.org/sqlite](https://gitlab.com/cznic/sqlite) — чистый Go, без CGO
- **FTS5** — полнотекстовый поиск по метаданным и OCR
- **[fsnotify](https://github.com/fsnotify/fsnotify)** — отслеживание файловой системы
- **[goexif](https://github.com/rwcarlsen/goexif)** — метаданные EXIF
- **[disintegration/imaging](https://github.com/disintegration/imaging)** — превью для обычных картинок
- **[bcrypt](https://pkg.go.dev/golang.org/x/crypto/bcrypt)** — хеширование пароля сейфа
- **Vanilla JS + CSS** на фронте — без сборщиков и фреймворков

### Внешние зависимости (опционально)

Для полного покрытия форматов:

| Инструмент | Зачем | Установка (Windows) |
|---|---|---|
| **ffmpeg** | Превью видео, HEIC, AVIF | `winget install Gyan.FFmpeg` |
| **ImageMagick** | Превью RAW (CR2, NEF, ARW...) | `winget install ImageMagick.ImageMagick` |
| **Tesseract** + русский язык | OCR — поиск по тексту внутри картинок | `winget install UB-Mannheim.TesseractOCR` |

Приложение работает и без них — просто не будут генерироваться превью для соответствующего типа файлов, а OCR-поиск отключится. В логе при старте видно, что найдено:

```
? ffmpeg найден
? ImageMagick найден
? tesseract найден
```

## Установка и запуск

### Готовый бинарник

1. Скачай последний релиз со страницы [Releases](../../releases)
2. Распакуй в любую папку
3. Запусти `media-gallery.exe` (Windows) / `media-gallery.app` (macOS)

**Windows**: требует WebView2 Runtime — на Windows 10/11 он уже установлен.
**macOS**: приложение не подписано; чтобы запустить, правый клик ? «Открыть», либо `xattr -d com.apple.quarantine media-gallery.app`.
**Linux**: нужен `webkit2gtk-4.0` (`sudo apt install libwebkit2gtk-4.0-dev`).

### Из исходников

```bash
# 1. Установить Wails CLI
go install github.com/wailsapp/wails/v2/cmd/wails@latest

# 2. Проверить окружение
wails doctor

# 3. Клонировать и собрать
git clone https://github.com/USERNAME/media-gallery.git
cd media-gallery
wails build
```

Готовый бинарник появится в `build/bin/`.

### Режим разработки

```bash
wails dev
```

Открывается окно с приложением, горячая перезагрузка фронтенда, DevTools по `F12`.

## Настройка сканирования

По умолчанию приложение сканирует домашнюю папку пользователя (`C:\Users\<user>`).

Можно указать свои папки через переменную окружения:

```powershell
$env:MEDIA_GALLERY_DIRS = "D:\Фото,D:\Видео,E:\Архив"
wails dev
```

Или установить на постоянно:

```powershell
[Environment]::SetEnvironmentVariable(
  "MEDIA_GALLERY_DIRS",
  "D:\Фото,D:\Видео",
  "User"
)
```

## Что хранится и где

Приложение **не изменяет** твои файлы (кроме кнопки «Удалить в корзину»). Вся служебная информация — в отдельных папках ОС:

- **База индекса**: `%APPDATA%\media-gallery\index.db` (Windows), `~/Library/Application Support/media-gallery/` (macOS), `~/.config/media-gallery/` (Linux)
- **Кэш превью**: `%LOCALAPPDATA%\media-gallery\thumbs\` (Windows), `~/Library/Caches/media-gallery/` (macOS), `~/.cache/media-gallery/` (Linux)

Чтобы сбросить всё — просто удали эти папки, приложение пересоздаст их с нуля.

## FAQ

**Почему не как в Google Photos — облако, шаринг?**
Потому что цель — локальная галерея. Хочешь шаринг — настрой Syncthing, Nextcloud или любую облачную папку и положи её в корни сканирования.

**Почему не Electron?**
Потому что Wails даёт тот же результат (HTML-интерфейс внутри нативного окна) при размере бинарника 8–15 МБ вместо 150+. Go-бэкенд работает на порядок быстрее, а WebView уже есть в системе.

**Почему SQLite, а не JSON-файл?**
Потому что на 100 000 файлов JSON не работает: любая фильтрация — полный скан в память. FTS5 + индексы дают мгновенный поиск даже по OCR-тексту.

**Приватность**
Ни одного сетевого запроса, кроме CDN Leaflet (уже убран). Никакой телеметрии. Всё работает офлайн.

**Зачем нужны внешние ffmpeg/ImageMagick/Tesseract, почему не встроены?**
Потому что каждый весит десятки мегабайт. Пользователь ставит только те, что ему нужны, — и получает полный формат-паритет за 100 МБ, а не раздутый 500-мегабайтный установщик.
